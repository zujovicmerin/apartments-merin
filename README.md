# Apartments Merin – GitHub-Paket

Dies ist der erste Website-Entwurf.

1. Diese ZIP vollständig entpacken.
2. Den Inhalt in dein GitHub-Repository hochladen. `index.html` muss im Hauptverzeichnis liegen; `assets` und `images` müssen als Ordner erhalten bleiben.
3. `.nojekyll` mit übernehmen.
4. GitHub Pages für den gewünschten Branch und dessen Hauptverzeichnis aktivieren. Die von GitHub angezeigte URL öffnen.

Der Repositoryname kann frei gewählt werden. Die relativen Assetpfade funktionieren auch unter einem Unterverzeichnis.

## Anfragen

In `site-config.json` könnt ihr eure tatsächliche E-Mail-Adresse und/oder WhatsApp-Nummer eintragen. Ohne diese Angaben werden Anfragen nur vorbereitet und kopiert. Mit einem Kontakt öffnet die Seite das E-Mail-Programm oder WhatsApp; Gäste versenden dort selbst.

Es gibt noch keine Live-Verfügbarkeit, Preisberechnung, Zahlungsabwicklung, verbindliche Buchung oder Synchronisierung mit Booking. Preise, Bedingungen, Betreiberangaben und Datenschutz müssen für den öffentlichen Buchungsbetrieb ergänzt werden. Der Entwurf hat deshalb eine noindex-Kennzeichnung.

## Bearbeitung

Die Datei Apartments_Merin_Quellcode.zip enthält den bearbeitbaren React-/CSS-Quellcode und die Originalbild-Zuordnung. Änderungen in kompilierten assets-Dateien sind nicht notwendig.
